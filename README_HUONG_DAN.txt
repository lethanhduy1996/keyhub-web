KEYHUB WEB - HUONG DAN UP GITHUB TREN IPHONE

1. Tai ZIP ve Files, bam ZIP de giai nen.
2. Safari > github.com > repository keyhub-web > Add file > Upload files.
3. Chon 7 tep (index.html, app.js, styles.css, sw.js, manifest.webmanifest, icon-192.png, icon-512.png) trong thu muc da giai nen.
4. Commit changes, bao dam 7 tep nam o thu muc goc cua repository.
5. Khong can upload README_HUONG_DAN.txt.
6. Sau do ket noi repository voi Cloudflare Pages, deploy nhung frontend chi hoat dong day du sau khi co backend FastAPI va database.
7. KHONG upload mat khau, .env, API secret.
